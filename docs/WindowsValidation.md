# Windows 검증

Qt 6.8.3 MinGW, Ninja, Python과 Rust의 Windows GNU 도구를 사용한다. 앱, 데몬, CLI 및 테스트는 저장소의 `build/` 아래에 빌드한다. 앱 실행은 Windows 플랫폼 플러그인에서 실제 창을 생성하고 정상 종료하는지 확인한다.

GitHub 원본에 `src/app/models/hierarchy/tags/` 폴더가 누락되어 앱 및 회귀 테스트를 구성할 수 없었다. 기존 프로젝트 계층 구현과 태그 호출부의 계약에 따라 태그 계층 저장·파싱·생성, 컨트롤러 및 허브별 상태를 구현하였다. 태그는 노트의 `tags` 목록으로 필터링하며, 계층의 깊이와 파일 바인딩을 유지한다. 파서가 깊이 처리를 직접 수행하므로 존재하지 않는 별도 flattener/JSON parser 파일의 빌드 참조는 제거하였다.

회귀 테스트는 한글 태그 이름과 중첩 깊이의 저장·재파싱, 허브 상태의 독립성과 제거를 실제 실행한다. Git의 전역 ctags 무시 패턴에 의해 소스가 다시 누락되지 않도록 추적 예외를 추가하였다.

Windows 드라이브 및 UNC 경로는 로컬 허브 경로로 판별한다. 손상된 JSON 태그 데이터는 텍스트 목록으로 전환하지 않고 오류를 반환하며, 회귀 테스트에서 두 동작을 검증한다.

일·주·월 캘린더 페이지는 부모 ContentViewLayout이 사용하는 overlayCloseRequested 신호를 제공한다. Escape 키로 동일한 닫기 요청을 발생시킨다. 실제 QML 페이지 생성 및 신호 전달 회귀와 앱 창 시작으로 검증한다.

연간 달력의 월 선택 연결은 실제 monthCalendarOpenRequested 신호를 사용하며, 런타임 테스트에서 신호 인수 전달까지 검증한다.
