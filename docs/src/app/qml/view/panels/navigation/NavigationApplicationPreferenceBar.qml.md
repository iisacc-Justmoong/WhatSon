# `src/app/qml/view/panels/navigation/NavigationApplicationPreferenceBar.qml`

<a id="responsibility"></a>

## 책임
`NavigationApplicationPreferenceBar.qml`는 공유 애플리케이션 수준 기본 설정/세부 사항 전환 세그먼트 래퍼입니다.

`NavigationApplicationViewBar.qml` 및 `NavigationApplicationEditBar.qml` 모두 이 단일 래퍼를 사용하므로 모드별 중복 래퍼 없이 세부 전환 동작이 공유됩니다.

<a id="composition"></a>

## 구성
- 루트: `NavigationPreferenceBar`
- 소스 종속성: `src/app/qml/view/panels/navigation/NavigationPreferenceBar.qml`
