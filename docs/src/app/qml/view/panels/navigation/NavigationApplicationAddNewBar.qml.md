# `src/app/qml/view/panels/navigation/NavigationApplicationAddNewBar.qml`

<a id="responsibility"></a>

## 책임
`NavigationApplicationAddNewBar.qml`는 공유 애플리케이션 수준의 새 추가 세그먼트 래퍼입니다.

`NavigationApplicationViewBar.qml` 및 `NavigationApplicationEditBar.qml`는 모두 이 단일 래퍼를 사용하므로 모드별 중복 래퍼 없이 새 추가 동작이 공유됩니다.

<a id="composition"></a>

## 구성
- 루트: `NavigationAddNewBar`
- 소스 종속성: `src/app/qml/view/panels/navigation/NavigationAddNewBar.qml`
