# `src/app/qml/view/panels/navigation/NavigationApplicationCalendarBar.qml`

<a id="responsibility"></a>

## 책임
`NavigationApplicationCalendarBar.qml`는 공유 애플리케이션 수준 달력 세그먼트 래퍼입니다.

`NavigationApplicationViewBar.qml` 및 `NavigationApplicationEditBar.qml` 모두 이 단일 래퍼를 사용하므로 달력 컨트롤이 모드 디렉터리별로 중복되지 않습니다.

<a id="composition"></a>

## 구성
- 루트: `NavigationCalendarBar`
- 소스 종속성: `src/app/qml/view/panels/navigation/NavigationCalendarBar.qml`
